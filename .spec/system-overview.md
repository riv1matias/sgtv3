## VISIÓN GENERAL DEL SISTEMA

El Sistema de Gestión de Tareas de Mantenimiento es una plataforma integral que controla el ciclo completo de vida de las tareas de mantenimiento, desde su creación hasta su finalización y aprobación de costos. El sistema implementa un flujo de trabajo estructurado con múltiples niveles de aprobación, control granular de permisos, auditoría completa y gestión de concurrencia.

### Características Principales:

- **Flujo de trabajo multi-nivel** con 11 estados diferentes
- **Sistema de roles flexible** con permisos granulares
- **Control de concurrencia** mediante bloqueo de tareas
- **Certificación dual** (proveedor emite, inspector edita)
- **Auditoría completa** con snapshots de datos
- **Límites de exportación** configurables por usuario
- **Notificaciones automáticas** en tiempo real
- **Jerarquías dinámicas** entre usuarios
